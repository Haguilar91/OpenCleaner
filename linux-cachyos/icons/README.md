# Bundled icons

`opencleaner.py` adds this folder to GTK's icon search path at startup, so the app looks the same on
every distro and icon theme.

- `hicolor/scalable/apps/local.opencleaner.OpenCleaner.svg`: the app icon, generated by
  `docs/brand/build_icons.py` (do not edit by hand).
- `hicolor/scalable/*/opencleaner-*-symbolic.svg`: UI icons copied from the GNOME Adwaita icon theme
  (adwaita-icon-theme, CC-BY-SA 3.0 or LGPL-3.0). They carry the `opencleaner-` prefix so the user's icon
  theme cannot replace them. To add one, copy it from `/usr/share/icons/Adwaita/symbolic/` with the
  prefix and use the prefixed name in the code.
