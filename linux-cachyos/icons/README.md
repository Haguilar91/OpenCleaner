# Bundled icons

`opencleaner.py` adds this folder to GTK's icon search path at startup, so the app looks the same on
every distro and icon theme.

- `hicolor/scalable/apps/local.opencleaner.OpenCleaner.svg`: the app icon, generated by
  `docs/brand/build_icons.py`.
- `hicolor/scalable/actions/opencleaner-*-symbolic.svg`: the UI icons, the same Lucide set as every other
  OpenCleaner app, generated by `docs/brand/build_ui_icons.py` from `docs/brand/ui-icons/` (filled outlines,
  since GTK colours symbolic icons by filling them). The `opencleaner-` prefix keeps the user's icon theme
  from replacing them.

Do not edit these files by hand: change the masters and rerun the scripts.
