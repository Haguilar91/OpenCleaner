# OpenCleaner 1.4

OpenCleaner now speaks Spanish. *(En español más abajo.)*

## Downloads

| System | File | Notes |
|---|---|---|
| Windows 10/11, Intel/AMD 64-bit | `OpenCleaner-1.4-Setup-x64.exe` | Most PCs. Also runs on Windows on ARM (emulated) |
| Windows on ARM | `OpenCleaner-1.4-Setup-arm64.exe` | Native build for ARM laptops |
| Windows 10, 32-bit | `OpenCleaner-1.4-Setup-x86.exe` | Older 32-bit systems |
| Windows, no install | `OpenCleaner-1.4-Windows-portable.exe` | Lightweight classic version |
| macOS 13+ | `OpenCleaner-1.4-macOS.zip` | Unzip and move to Applications |
| Linux x86_64 | `opencleaner-1.4-linux-x86_64` | Single file, `chmod +x` then run |
| Linux ARM64 (64-bit Raspberry Pi OS, ARM laptops) | `opencleaner-1.4-linux-arm64` | Single file, `chmod +x` then run |
| Android 11+ phones and tablets | `OpenCleaner-1.4-android.apk` | Installs over 1.3 |
| Android TV, Google TV, Fire TV (Android 9+, Fire OS 7+) | `OpenCleaner-1.4-androidtv.apk` | Installs over 1.3 |

Checksums are in `SHA256SUMS.txt`. Already on 1.3? Use **Update** inside the app.

## What's new

- **Spanish.** Every app (Windows, macOS, Linux, Android and Android TV) is now in English and Spanish
  and follows your system language, with nothing to set. On Android 13+ you can also choose the language
  for OpenCleaner alone in the system settings.
- **Fits better:** the disk map legend wraps instead of being cut off on narrow phones, the macOS Disk
  usage toolbar no longer cuts off its buttons, and the Windows classic version's "Sort" and "Show"
  labels are no longer clipped.
- **A one-minute video** of OpenCleaner, in English and in Spanish, is on the project page.
- **Built in the open:** every file in this release is built and tested on GitHub Actions from the
  source in this repository.

## Good to know

- The Windows installers are not code-signed, so SmartScreen shows "Unknown publisher": click **More
  info**, then **Run anyway**. The macOS app is not notarized: the first time, right-click it and choose
  **Open**.
- The update check is a single request to `api.github.com` when the app starts; nothing about you or
  your files is sent.

## En español

OpenCleaner ya está en español.

- **Todas las apps en español:** Windows, macOS, Linux, Android y Android TV. Usan el idioma del sistema,
  así que no hay que configurar nada. En Android 13 o más reciente también puedes elegir el idioma solo
  para OpenCleaner en los ajustes del sistema.
- **Mejor ajuste:** la leyenda del mapa del disco pasa a una segunda línea en vez de cortarse, la barra de
  Uso del disco en macOS ya no corta sus botones, y en la versión clásica de Windows ya no se cortan
  "Orden" y "Mostrar".
- **Un video de un minuto** sobre OpenCleaner, en inglés y en español, en la página del proyecto.
- **Compilado a la vista:** cada archivo de esta versión se compila y se prueba en GitHub Actions a partir
  del código de este repositorio.

¿Ya tienes la 1.3? Usa **Actualizar** dentro de la app. Los instaladores de Windows no están firmados: si
SmartScreen avisa, haz clic en **Más información** y luego en **Ejecutar de todas formas**. En macOS, la
primera vez haz clic derecho en la app y elige **Abrir**.
