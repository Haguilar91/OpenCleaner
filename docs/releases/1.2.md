# OpenCleaner 1.2

Open-source disk cleaner for Windows, macOS, Linux and Android: scan, review sizes, tick, confirm,
clean. Nothing is deleted until you tick it and confirm.

## Downloads

| System | File | Notes |
|---|---|---|
| Windows 10/11, Intel/AMD 64-bit | `OpenCleaner-1.2-Setup-x64.exe` | Most PCs. Also runs on Windows on ARM (emulated) |
| Windows on ARM | `OpenCleaner-1.2-Setup-arm64.exe` | Native build for ARM laptops |
| Windows 10, 32-bit | `OpenCleaner-1.2-Setup-x86.exe` | Older 32-bit systems |
| Windows, no install | `OpenCleaner-1.2-Windows-portable.exe` | Lightweight classic version, runs on the .NET Framework built into Windows |
| macOS 13+ | `OpenCleaner-1.2-macOS.zip` | Unzip and move to Applications |
| Linux x86_64 | `opencleaner-1.2-linux-x86_64` | Single file, `chmod +x` then run |
| Linux ARM64 (64-bit Raspberry Pi OS, ARM laptops) | `opencleaner-1.2-linux-arm64` | Single file, `chmod +x` then run |
| Android 11+ | `OpenCleaner-1.2-android.apk` | Allow "Install unknown apps" for your file manager |

Checksums are in `SHA256SUMS.txt`.

## What's new

- **New look.** New OpenCleaner icon (a silver drive with a blue sweep), brand colors on every
  platform, and the Ubuntu font on Android (and on Linux when it is installed).
- **Preview before you delete.** Click a file in Disk usage to see it first: images, the start of
  text files, size, date and location, with Open and Delete. In Clean, the eye button (**Review**)
  lists the files inside an item so you can check them before ticking it.
- **Built-in player** for mp4, mp3, flac and other video and audio (macOS, Android, Linux, Windows
  WinUI).
- **Disk map.** A WinDirStat-style map of the current folder: colored blocks sized by space, by file
  type. Click a folder to go in, click a file to preview it.
- **Sort and Top N.** Sort by biggest, oldest, newest or file type, and show only the top 5, 10, 50
  or 100. A percentage shows while sizes are being measured.
- **Apps page.** Installed apps with their size and when they were last used, sortable by size,
  least or most recently used, or name, with the same Top choices.
- **Uninstall with leftovers** (Windows, macOS, Linux). Removes the app and shows its leftover files
  first (caches, preferences, settings) so you choose what goes. Folders that may hold your data
  start unticked. **Uninstalling deletes permanently: nothing goes to the Trash or Recycle Bin.**
  On Android it opens the system's own uninstall prompt.
- **Linux: works on more distros.** Detects the distro and uses its package manager: Arch, CachyOS,
  Omarchy and Arch Linux ARM (pacman); Debian, Ubuntu, Linux Mint and Raspberry Pi OS (APT, plus old
  Snap revisions); Fedora and Rocky Linux (DNF); Bazzite and other image-based systems (system
  packages left alone, Flatpak only). Runs on GTK 4.8 / libadwaita 1.2 and newer, so Debian 12 and
  Raspberry Pi OS work too.
- **Windows installer.** A normal setup program (per-user, no admin prompt), with Start menu entry,
  optional desktop shortcut and uninstaller, for x64, ARM64 and 32-bit.
- **Linux single-file builds** for x86_64 and ARM64, no installation needed.

## Good to know

- The Windows installers are not code-signed, so Windows SmartScreen shows "Unknown publisher".
  Click **More info**, then **Run anyway**.
- The macOS app is not notarized. The first time, right-click it, choose **Open**, then confirm.
- The Android APK is debug-signed. It installs over earlier OpenCleaner test builds.
- The Linux single-file builds use your system's display libraries (Wayland, X11, OpenGL), which every
  desktop already has. If video does not play in the single-file build, running from source
  (`python3 opencleaner.py`) uses your system's GStreamer.
- "Last used" is exact on macOS (Spotlight) and Android (usage access), and approximate on Linux
  (the program file's access time) and Windows (Explorer's launch history).
- The Windows features added in this release (preview, map, sort, Apps page, uninstall) are the least
  tested part of 1.2. Please report anything odd.

## Safety

Every clean and uninstall shows what it will remove and waits for your confirmation. Each item can
only delete inside its own folders; anything else is refused. Files in use are skipped, never forced.
