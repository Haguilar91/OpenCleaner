# OpenCleaner 1.3

Thanks for the feedback on 1.2. This release adds what you asked for, plus updates from inside the app.

## Downloads

| System | File | Notes |
|---|---|---|
| Windows 10/11, Intel/AMD 64-bit | `OpenCleaner-1.3-Setup-x64.exe` | Most PCs. Also runs on Windows on ARM (emulated) |
| Windows on ARM | `OpenCleaner-1.3-Setup-arm64.exe` | Native build for ARM laptops |
| Windows 10, 32-bit | `OpenCleaner-1.3-Setup-x86.exe` | Older 32-bit systems |
| Windows, no install | `OpenCleaner-1.3-Windows-portable.exe` | Lightweight classic version |
| macOS 13+ | `OpenCleaner-1.3-macOS.zip` | Unzip and move to Applications |
| Linux x86_64 | `opencleaner-1.3-linux-x86_64` | Single file, `chmod +x` then run |
| Linux ARM64 (64-bit Raspberry Pi OS, ARM laptops) | `opencleaner-1.3-linux-arm64` | Single file, `chmod +x` then run |
| Android 11+ phones and tablets | `OpenCleaner-1.3-android.apk` | Installs over 1.2 |
| Android TV, Google TV, Fire TV (Android 9+, Fire OS 7+) | `OpenCleaner-1.3-androidtv.apk` | New: works with the remote |

Checksums are in `SHA256SUMS.txt`.

## What's new

- **Delete several files at once.** Tick files and folders in Disk usage and delete them together.
  A bar at the bottom shows how many are selected and how much space they take.
- **Delete from the disk map.** Right-click a block (long-press on Android) to select it; selected
  blocks get a white outline. The map and the list share the same selection.
- **Trash or permanent.** A new setting in Disk usage: **Move to Trash** (the default, so you can
  undo) or **Delete permanently**. The confirmation always says which one will happen. Android has no
  trash for files, so deletes there are always permanent and say so.
- **Uninstall apps that need administrator rights**, like Microsoft Office. On Windows the uninstaller
  runs through the UAC prompt, and OpenCleaner waits until the program is really gone before cleaning
  its leftovers. On macOS, apps that belong to the system ask for your administrator password.
- **New: OpenCleaner for TV.** A separate app for Android TV, Google TV and Fire TV (including older
  Fire TV on Fire OS 7). Everything works with the remote: a menu on the left, a clear highlight on
  what is selected, and OK on a map block opens a small menu to open, select or delete it. Many TVs
  have no settings page for "All files access" or "Usage access"; the app then shows the one `adb`
  command that grants it.
- **Updates from inside the app.** OpenCleaner checks GitHub for a newer release when it starts and has
  a "Check for updates" button. Updates are checked against the release checksums before they are
  installed.

## Good to know

- **Update by hand to 1.3 once.** 1.2 has no updater. From 1.3 on, OpenCleaner updates itself.
- The update check is a single request to `api.github.com` when the app starts; nothing about you or
  your files is sent.
- Uninstalling still deletes permanently, after a review and a warning.
- The Windows installers are not code-signed, so SmartScreen shows "Unknown publisher": click **More
  info**, then **Run anyway**. The macOS app is not notarized: the first time, right-click it and choose
  **Open**.
- The Linux single-file builds use your system's display libraries (Wayland, X11, OpenGL), which every
  desktop already has.
